ETIKPRO — Gestion des licences

OMZAKREVO INFORMATIQUE · Toujours une solution !

1. Nouvelle licence

Donnez cette clé au client. Elle n'est stockée nulle part en clair : notez-la.

Sur GitHub : dépôt etikpro-licences › licences.json › ✏️ Modifier › collez le bloc dans la liste (n'oubliez pas la virgule entre deux blocs) › Commit changes.

2. Retrouver une licence existante

Pour prolonger ou suspendre : calculez l'empreinte de la clé, cherchez-la dans licences.json, puis modifiez "expire" ou "actif".
